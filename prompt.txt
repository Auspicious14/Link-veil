Endpoints
POST /api/links

Auth required.

Validate body with Zod.

Generate a short unique ID using nanoid or custom util.

Return full shortened link: https://linkveil.app/l/:shortId.

GET /api/links/:shortId

If public → return real URL immediately.

If request → return metadata but not URL; only reveal URL if user approved.

If private → return 403 unless user is owner.

POST /api/links/:shortId/request-access

Save access request for logged-in or anonymous user (email required).

Prevent duplicate requests.

Return status pending or approved.

POST /api/links/:shortId/approve

Only link owner can approve.

Adds requester to approvedUsers.

GET /api/links/:shortId/stats

Return click count and basic analytics.
